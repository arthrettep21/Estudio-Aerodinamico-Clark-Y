# Estudio-Aerodinámico-Clark-Y
Repositorio de datos aerodinámicos del perfil Clark Y: archivos crudos extraídos de XFLR5 y datos procesados.

Nota explicativa sobre la nomenclatura:
Los identificadores que aparecen corresponden a la nomenclatura automática que usa el software XFLR5 para registrar cada caso de simulación con flujo forzado. Cada código muestra las condiciones operativas y la ubicación del trip de la siguiente forma:
•	T1: Indica el tipo de polar calculada (Polar Tipo 1, que se realiza a número de Reynolds constante y ángulo de ataque variable).
•	Re0.066: Muestra el número de Reynolds de la simulación (en este ejemplo, Re = 66.000).
•	M0.00: Define el número de Mach de la condición de ensayo (M = 0,00, lo que significa flujo incompresible).
•	N9.0: Indica el factor de amplificación e^N que se usa en el método e^N para modelar la transición laminar-turbulenta (Ncrit = 9,0, valor normal para flujo en aire libre o en túnel de baja turbulencia).
•	XtrTop45%: Muestra la posición forzada de la transición o ubicación del trip en la superficie superior (extradós), dada como porcentaje de la cuerda (en este caso, x/c = 45%).
